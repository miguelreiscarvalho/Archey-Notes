# Ícones do Estúdio

`library.svg`, `new.svg`, `export.svg` e `backup.svg` são cópias dos recursos Lucide já distribuídos pelo Xournal++ 1.3.8 (`ui/iconsLucide-light/hicolor/scalable/actions`): `xopp-sidebar-index`, `xopp-document-new`, `xopp-document-export-pdf` e `xopp-sidebar-layerstack`.

`share.svg` é `Adwaita/symbolic/actions/send-to-symbolic.svg` do runtime GTK instalado no laboratório. Mantidas as formas originais; a interface define tamanho e adaptação ao tema via CSS. A procedência dos conjuntos é preservada; esta pasta não atribui uma licença nova aos arquivos de terceiros.
