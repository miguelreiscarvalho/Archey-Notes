# Ícones da navegação

Origem: [Sidebar Navigation — Proton UI (Community)](https://www.figma.com/design/MeSNq0U9paewum8jTqrbiO), componente `51:544`, consultado em 06/11/2026 via integração Figma.

SVGs exportados e armazenados sem alterações: Home, Stats, Income, Message, Left Arrow, Sun e Moon. Usados em slots de 24px (menu) e 18px (seta/tema), respeitando as dimensões intrínsecas dos arquivos.

A marca X+ e os dados exibidos no rodapé pertencem à interface local do laboratório; não representam a marca ou a conta de exemplo do template.
